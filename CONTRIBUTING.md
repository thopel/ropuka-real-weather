# Contributing

Contributions are welcome. Keep changes narrowly scoped and do not commit game files, BepInEx binaries, generated build output, logs, or personal configuration files.

Before opening a pull request:

1. Build the project against a legitimate local game installation.
2. Run the complete test suite.
3. Verify that the game can start, navigate its settings, synchronize weather, and exit normally.
4. Document user-facing changes in the pull request.

Please avoid runtime patches or changes to the game's save/settings data unless the behavior is explicitly discussed and justified first.
